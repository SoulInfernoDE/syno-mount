Syno Mount 0.6.1 fixes how a stopped folder is shown on Linux.

## Fixed

- A folder that was disconnected on purpose showed "Failed". sshfs ends with an error code when it is stopped, so systemd marked the mount as failed. Because of that, the agent could also start such a folder again after the next network change if it is set to connect at sign-in. Stopping now clears this state, and the folder shows "Not mounted".

## Downloads

Linux: `.deb`, `.rpm`, `.AppImage` for x86_64 and arm64. Windows: `-setup.exe` (per user) or `.msi`; the installers are not signed yet, so SmartScreen may warn. Check with `sha256sum -c SHA256SUMS.txt`.

## Deutsch

Syno Mount 0.6.1 behebt, wie ein gestoppter Ordner unter Linux angezeigt wird.

### Behoben

- Ein absichtlich getrennter Ordner zeigte „Fehlgeschlagen“. sshfs endet beim Stoppen mit einem Fehlercode, deshalb hat systemd die Verbindung als fehlgeschlagen markiert. Dadurch konnte der Agent einen solchen Ordner nach dem nächsten Netzwechsel auch wieder verbinden, wenn er bei der Anmeldung verbinden soll. Das Stoppen setzt diesen Zustand jetzt zurück, und der Ordner zeigt „Nicht eingebunden“.

### Downloads

Linux: `.deb`, `.rpm`, `.AppImage` für x86_64 und arm64. Windows: `-setup.exe` (pro Benutzer) oder `.msi`; die Installer sind noch nicht signiert, SmartScreen kann deshalb warnen. Prüfen mit `sha256sum -c SHA256SUMS.txt`.
